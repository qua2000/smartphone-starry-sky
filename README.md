# smartphone-starry-sky

スマホの現在地・時刻・向きから、見える天体をカメラ映像に重ねて表示するための、初心者向けの小さな実験プロジェクトです。

## いま実装していること：④ 月の方位角・高度の計算

`index.html` をスマホのChromeで開くと、カメラ映像、現在時刻、現在地、スマホの向きを確認した後、**現在地と現在時刻から月が空のどこにあるか**を計算できます。

| 順番 | 操作 | 画面に起きること |
|---|---|---|
| 1 | `カメラを開始する` を押して許可する | 後ろ向きカメラのライブ映像が表示される |
| 2 | `現在地を取得する` を押して許可する | 現在の緯度・経度・位置の精度が表示される |
| 3 | `月の位置を計算する` を押す | 月の方位角、高度、地平線より上か下かが表示される |
| 任意 | `スマホの向きを取得する` を押す | 方位角の目安と傾きが表示される。今回は月の数値の確認には必須ではない |

> この段階では、月の位置を**数値として計算・表示するだけ**です。月の絵や印をカメラ映像へ重ねるのは、次の⑤で行います。

## 月の位置を表す二つの数字

月の位置は、現在地から見た「方位角」と「高度」で表します。

| 項目 | 意味 | 数字の例 |
|---|---|---|
| 月の方位角 | 地平線に沿った方向。北を0°として、時計回りに測る | 90°は東、180°は南、270°は西 |
| 月の高度 | 地平線からどれだけ上にあるか | 0°は地平線、90°は真上。マイナスなら地平線の下 |
| 月の見える状態 | 高度から判断した月の状態 | 高度が0°より大きければ、計算上は空にある |

たとえば「月の方位角：120°（南東）、月の高度：35°」なら、月は南東の空で、地平線からかなり上にあります。次の⑤では、この二つの数字とスマホの方位・傾きを比較して、画面上のどこへ月の印を置くかを決めます。

## 計算方法について

このページは、ブラウザ上で使えるオープンソースの **SunCalc 2.0.1** を読み込み、`現在時刻・緯度・経度` を渡して月の方位角と高度を計算します。SunCalcの `getMoonPosition` は、月の方位角を北から時計回りの度数、高度を地平線からの度数として返します。[SunCalc公式ドキュメント](https://github.com/mourner/suncalc)

計算は利用者のスマホ内で行います。現在地を外部の天文計算サービスへ送る処理は入れていません。ただし、SunCalcを読み込むため、初回にはCDNから小さなJavaScriptファイルを取得します。
