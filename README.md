# smartphone-starry-sky

スマホの現在地・時刻・向きから、見える天体をカメラ映像に重ねて表示するための、初心者向けの小さな実験プロジェクトです。

## いま実装していること：② 現在地と時刻の表示

`index.html` をスマホのChromeで開くと、次の順に確認できます。

1. `カメラを開始する` を押し、後ろ向きカメラのライブ映像を表示します。
2. カメラ映像上のカードに、現在時刻が1秒ごとに表示されます。
3. `現在地を取得する` を押し、Chromeの位置情報の確認画面で `許可` を選びます。
4. 緯度、経度、位置情報の精度の目安がカメラ映像上に表示されます。

> この段階では、位置と時刻を画面に表示するだけです。方位、月、星はまだ扱いません。

## スマホでの確認方法

HTTPSの公開URLを、スマホのChrome（Android）で開いてください。カメラと位置情報は、それぞれ別々に許可します。

| 表示された内容 | 選ぶ操作 |
|---|---|
| 「カメラへのアクセスを許可しますか」 | **許可** |
| 「位置情報の使用を許可しますか」 | **許可** |
| 緯度・経度・精度が表示された | ②は成功です |
| 位置情報の取得に失敗した | スマホ本体の位置情報が有効か、Chromeの権限が許可されているかを確認します |

カメラ映像と位置情報は、このページで表示するためにだけ使います。映像や現在地を保存・送信する処理は入れていません。

## 参考資料

- カメラ映像をWebページで扱う `getUserMedia()` は、利用者の許可が必要で、HTTPSなどの安全な環境で利用します。[MDN Web Docs: MediaDevices.getUserMedia()](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)
- 位置情報は `navigator.geolocation` を使って取得でき、利用者の許可が必要です。[MDN Web Docs: Geolocation API](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API)
