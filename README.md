# smartphone-starry-sky

スマホの現在地・時刻・向きから、見える天体をカメラ映像に重ねて表示するための、初心者向けの小さな実験プロジェクトです。

## いま実装していること：⑤ 月の予測位置をカメラ映像へ重ねる

この段階では、月の名前はまだ表示しません。月の方位角・高度とスマホの向きの情報を比べ、**月がカメラの視野内にあると計算されたときだけ、琥珀色の丸印をカメラ映像に重ねる**ようにしています。

| 順番 | 操作 | 画面に起きること |
|---|---|---|
| 1 | `カメラを開始する` を押す | カメラ映像と現在時刻が表示される |
| 2 | `現在地を取得する` を押す | 月を計算するための緯度・経度を取得する |
| 3 | `スマホの向きを取得する` を押す | カメラが向く方向を判断するための方位・傾きを取得する |
| 4 | `月の位置を計算する` を押す | 月の方位角と高度が計算される |
| 5 | `月の予測位置を重ねる` を押す | 月が視野内なら、カメラ映像上に丸印が現れる |

> 丸印は「カメラが月を見つけた」印ではありません。現在地・時刻・スマホの姿勢から計算した、**月があるはずの予測位置**です。

## 丸印が出る条件

丸印を出すには、次の三つの条件がすべてそろう必要があります。

| 条件 | 画面での確認方法 | そろわない場合の表示 |
|---|---|---|
| 月が地平線より上にある | 月の高度が `0°より大きい` | 「月は現在、地平線より下にあります」 |
| スマホの向きが取得できている | 方位角の目安などに数字が出る | 「先にスマホの向きを取得してください」 |
| 月がカメラの視野内にある | 月の方位角・高度に近い方向へ向ける | 「月はカメラの画面外にあります」 |

先ほどの確認結果では月の高度がマイナスだったため、今すぐ丸印が出ないことは正常です。月の高度が正の値になる時間帯にもう一度試すと、表示を確認できます。

## 何を計算しているか

月の方位角・高度は、地平線を基準にした空の位置です。一方、スマホのセンサーは、端末自体がどの向き・どの傾きかを返します。⑤では、この二つを同じ向きの情報として比べるために、次の小さな変換を行っています。

| 変換 | 初心者向けの意味 |
|---|---|
| 月の方位角・高度 → 3次元の矢印 | 地図上の「方向」と空の「高さ」を、空間の矢印にする |
| 地球を基準にした矢印 → スマホを基準にした矢印 | 月がスマホの前、後ろ、右、左、上、下のどこにあるか調べる |
| スマホを基準にした矢印 → 画面の座標 | 月が画面の中央、右上、左下など、どこに置かれるべきか決める |

カメラの視野角は機種ごとに異なるため、この最初の版では多くのスマホを想定した近似値を使っています。よって丸印は、まず「月の方向へスマホを向ける案内」として使い、実際の月にぴったり重ねるための校正・補正は今後の発展項目とします。ブラウザや端末によって方向センサーの座標系や値の扱いに差がありうることも、開発者向け資料で注意されています。[web.dev: Device Orientation & Motion](https://web.dev/articles/device-orientation)

## 実機での確認方法

月が地平線より上にある時間帯に、見通しがよく安全な場所で試してください。夜空を見上げながら歩かず、足元と周囲を確認してからスマホを操作してください。

月の方位角と高度を手がかりにして、まず方位角に近い方角へスマホを向けます。続いて、地平線から月の高度に近い角度まで、ゆっくりスマホを上へ向けます。丸印が表示されたら、実際の月の近くにあるかを確認します。大きくずれていても、⑤の段階では失敗ではありません。まずは丸印が画面に現れるか、スマホを動かすと位置も動くかを確認してください。
