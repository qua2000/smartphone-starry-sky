# smartphone-starry-sky

スマホの現在地・時刻・向きから、見える天体をカメラ映像に重ねて表示するための、初心者向けの小さな実験プロジェクトです。

## いま実装していること：③ スマホの向きの表示

`index.html` をスマホのChromeで開くと、次の順に確認できます。

| 順番 | 操作 | 画面に起きること |
|---|---|---|
| 1 | `カメラを開始する` を押して許可する | 後ろ向きカメラのライブ映像が表示される |
| 2 | `現在地を取得する` を押して許可する | 現在の緯度・経度・位置の精度が表示される |
| 3 | `スマホの向きを取得する` を押す | 方位角の目安、前後の傾き、左右の傾きが動いて表示される |

> この段階では、位置・時刻・スマホの向きという「材料」を取得して画面に表示するだけです。月や星を描く処理はまだ入れていません。

## 数字の見方

スマホの姿勢を表す数値は、`DeviceOrientationEvent` というWebの仕組みから得ています。値はすべて角度で、単位は度（°）です。

| 画面に表示する項目 | 何を表すか | 簡単な確認方法 |
|---|---|---|
| 方位角の目安 | スマホが向く方向。0°は北、90°は東、180°は南、270°は西に近い | ゆっくり一回転して、数値と方角表示が変わるかを見る |
| 前後の傾き（beta） | スマホを前後へ倒したときの傾き | スマホの上側を前後に倒して、数字が変わるかを見る |
| 左右の傾き（gamma） | スマホを左右へ傾けたときの傾き | スマホを右・左に傾けて、数字が変わるかを見る |
| センサー状態 | 方位を含む情報か、動きの変化を基準にした情報かという状態 | `絶対方位の情報あり` と表示されるかを確認する |

初期段階で表示する方位角は、センサーから得た値を簡易的に方角へ換算した**目安**です。月を正しい場所に重ねる段階では、画面の縦横、スマホの傾き、カメラの画角を合わせて扱うため、より丁寧に調整します。

## うまく数値が出ない場合

Chromeでセンサーの数値が表示されないときは、スマホ本体の位置情報やセンサーが有効か、Chromeがこのサイトのモーションセンサー利用を許可しているかを確認します。また、ケースの磁石や近くの金属・電子機器はコンパスの値を乱すことがあります。まずは数字が動くことを確認できれば、③としては成功です。

## 参考資料

- カメラ映像をWebページで扱う `getUserMedia()` は、利用者の許可が必要で、HTTPSなどの安全な環境で利用します。[MDN Web Docs: MediaDevices.getUserMedia()](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)
- 位置情報は `navigator.geolocation` を使って取得でき、利用者の許可が必要です。[MDN Web Docs: Geolocation API](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API)
- `DeviceOrientationEvent` は、端末の物理的な向きに関する値を提供します。`alpha`、`beta`、`gamma` はそれぞれ異なる軸まわりの回転を度数で表します。[MDN Web Docs: DeviceOrientationEvent](https://developer.mozilla.org/en-US/docs/Web/API/DeviceOrientationEvent)
