# smartphone-starry-sky

スマホの現在地・時刻・向きから、見える天体をカメラ映像に重ねて表示するための、初心者向けの小さな実験プロジェクトです。

## いま実装していること：① カメラ映像の表示

`index.html` をスマホのブラウザで開き、**「カメラを開始する」**ボタンを押すと、後ろ向きカメラのライブ映像を表示します。

この段階では、位置情報、時刻、スマホの向き、月、星の名前はまだ扱いません。まずカメラ映像だけが正しく表示できることを確認します。

## スマホでの確認方法

GitHub Pagesで公開されたURLを、スマホのSafari（iPhone）またはChrome（Android）で開いてください。画面のボタンを押したら、ブラウザからカメラ使用の許可が求められます。

| 表示された内容 | 選ぶ操作 |
|---|---|
| 「カメラへのアクセスを許可しますか」 | **許可** |
| 前面カメラが映る | 端末のカメラの切替があれば、背面カメラへ変更する |
| 何も映らない・エラーになる | HTTPSの公開URLで開いているか、ブラウザの権限設定を確認する |

> 映像は画面に表示するだけで、保存・送信しません。
