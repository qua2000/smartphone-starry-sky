# smartphone-starry-sky

スマホの現在地・時刻・向きから、見える天体をカメラ映像に重ねて表示するための、初心者向けの小さな実験プロジェクトです。

## いま実装していること：⑥ NameボタンでMoonを表示する

月の予測位置を示す琥珀色の丸印がカメラ映像に表示されたとき、**`Name` ボタンを押すと、丸印の近くに `Moon` と表示**されます。もう一度ボタンを押すと、名前を隠せます。

| 順番 | 操作 | 画面に起きること |
|---|---|---|
| 1 | `カメラを開始する` を押す | カメラ映像と現在時刻が表示される |
| 2 | `現在地を取得する` を押す | 月の位置を計算するための緯度・経度を取得する |
| 3 | `スマホの向きを取得する` を押す | カメラが向く方向を判断するための方位・傾きを取得する |
| 4 | `月の位置を計算する` を押す | 月の方位角と高度が計算される |
| 5 | `月の予測位置を重ねる` を押す | 月が視野内なら、カメラ映像上に琥珀色の丸印が現れる |
| 6 | `Name` を押す | 丸印の近くに `Moon` と表示される |

> `Moon` は、カメラが月を画像認識した結果ではありません。現在地・時刻・スマホの姿勢から計算した、**月の予測位置を示す丸印の名称**です。

## Nameボタンが使える条件

Nameボタンは、月の丸印が表示されているときだけ使えるようにしています。この設計により、画面外の天体や地平線より下の月に対して、名前だけが不自然に表示されることを防げます。

| 状態 | Nameボタン | 理由 |
|---|---|---|
| 月が地平線より下 | 押せない | 空にない月の名前は表示しない |
| 月が地平線より上だが画面外 | 押せない | 丸印が見えていないため |
| 月の丸印が画面内にある | 押せる | 丸印とMoonの関係が分かる |
| Moonを表示中 | `Nameを隠す` と表示 | もう一度押すと名前を隠せる |

## 知っておくとよい制限

この初期版は学習用の小さな実験です。月の丸印の位置は、多くのスマホでの見え方を想定したカメラ視野角を使う近似です。実際の月とぴったり重ねるには、端末ごとのカメラ画角、コンパスの誤差、スマホの画面向きなどを補正する機能が今後必要になります。

ただし、①〜⑥を通じて、星空ARアプリの中心となる流れ、すなわち **「位置・時刻・端末姿勢を取得し、天体の予測位置をカメラ映像へ重ねる」** ところまでを一通り体験できています。
